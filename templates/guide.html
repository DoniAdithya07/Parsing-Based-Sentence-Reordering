Guide

How To Use The App

A quick step-by-step path for comparing baseline and parsing-based sentence reordering.

Step 1: Prepare Text

  • Use at least 3 sentences
  • You can paste one paragraph or one sentence per line
  • Keep punctuation for better parsing quality

Step 2: Run A Method

  • Run Baseline: fast heuristic output
  • Run Parsing: syntax-aware output
  • Compare Both: side-by-side comparison

Project Pipeline

  • Step 1: Parse Sentence - Dependency (implemented), Constituency (planned)
  • Step 2: Apply Reordering - Rule-Based (implemented), Statistical + Neural (planned)
  • Step 3: Generate Output Sentence - final ordered sentence (implemented)

Step 3: Read Results

  • Copy either output quickly with copy buttons
  • Check score percentages
  • In compare mode, inspect row-level differences

Step 4: Analyze Parsing Cards

  • View Subject, Verb, Object extraction
  • Use cards to understand ordering decisions
  • Try multiple samples to compare consistency

Tips

  • Use the Reuters dataset sample loader
  • Keep sentence count moderate (3-15) for cleaner output
  • Use History page to track and compare past runs

Troubleshooting

  • If no output appears, ensure text has 3+ sentences
  • If parsing is slow, reduce input size and retry
  • Install en_core_web_sm if parser output fails
