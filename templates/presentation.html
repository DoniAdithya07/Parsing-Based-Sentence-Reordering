1) About Our Project

1. Project Title

Parsing-Based Sentence Reordering with Baseline Comparison

2. What This Project Is

This project is an NLP web application that takes shuffled sentences and rearranges them into a more coherent order. It compares two approaches:

  • A simple baseline method
  • A parsing-based method (main approach)

It also shows analysis, evaluation metrics, and parsing logic in the website.

3. Problem Statement

When sentence order is disturbed, text becomes hard to understand. Many systems (summarization, question answering, content generation) need correct sentence flow.

Main problem: Given unordered sentences, generate a coherent sequence automatically.

4. Objective

  • Build an end-to-end system for sentence reordering.
  • Compare baseline vs parsing-based output.
  • Measure quality with proper evaluation metrics.
  • Provide an explainable UI for analysis and presentation.

5. Dataset Used

Reuters-21578 (via NLTK/local corpus files)

Key facts:

  • Total documents: 10,788
  • Categories/topics: 90
  • Standard split: 7,769 train / 3,019 test (corpus standard)
  • In our app, Reuters is used as a trusted sentence source for sample/demo inputs.

6. Method Used in Our Project

6.1 Baseline Method

  • Sorts sentences using simple surface logic (length-based ordering).
  • Computes local coherence via adjacent word overlap.

6.2 Parsing-Based Method (Main)

  • Uses spaCy dependency parsing (en_core_web_sm).
  • For each sentence, score uses syntax signals:
  • subject count
  • object count
  • root verb presence
  • proper nouns
  • pronoun penalty
  • Scores are normalized, then sentences ranked by score.

Core intuition: Syntax-aware signals help produce better sentence flow than naive ordering.

7. Evaluation Metrics (Shown in Website)

We compare outputs using:

  • Exact Match
  • PMR (Perfect Match Ratio)
  • Pairwise Accuracy
  • Kendall Tau

Interpretation:

  • Higher Exact Match / PMR / Pairwise Accuracy is better.
  • Kendall Tau closer to +1 is better.

8. System Workflow

  • User enters 3+ sentences (or loads Reuters sample).
  • User selects method: Baseline / Parsing / Compare.
  • Backend processes and generates reordered outputs.
  • UI shows:
  • Baseline output
  • Parsing output
  • Sentence flow graph
  • Evaluation metrics table
  • Parsing logic preview (Subject/Verb/Object)

9. Project Architecture

  • Frontend: HTML, CSS, JavaScript
  • Backend: Flask (Python)
  • NLP: spaCy + NLTK
  • Storage: SQLite for run history
  • Auth: Firebase Google Sign-In

10. Innovation / Novelty

  • Combines rule-like baseline and parsing-based ranking in one interactive app.
  • Adds explainability through parsing cards and flow graph.
  • Shows evaluation metrics directly in UI for academic analysis.
  • Lightweight, practical, and presentation-friendly implementation.

11. Why This Project (Why not only other models)

  • It is explainable (easy to justify in viva).
  • Low compute, fast to run locally.
  • Good educational value for syntax + coherence concepts.
  • Transparent comparison with baseline.
  • Easier deployment and maintenance than large black-box models.

12. Limitations

  • Parsing score is heuristic, not deep semantic understanding.
  • Mostly local sentence-level scoring.
  • Not a large transformer trained end-to-end for ordering.
  • Domain shift can affect quality.

13. Future Improvements

  • Add transformer-based reranker for stronger semantic ordering.
  • Add discourse-level features and entity grids.
  • Train/evaluate on multiple domains.
  • Add more robust human-evaluation benchmarking.

14. Final Conclusion

This project successfully demonstrates that syntax-aware parsing signals can improve sentence ordering quality over a simple baseline, while keeping the system interpretable, fast, and suitable for real academic demonstration.

2) About the Research Paper

Probabilistic Text Structuring: Experiments with Sentence Ordering

Author: Mirella Lapata

1. Introduction

In Natural Language Processing (NLP), generating a coherent and meaningful text requires arranging sentences in the correct order. This problem is known as sentence ordering or text structuring.

This paper addresses the challenge of:

Automatically arranging a set of unordered sentences into a coherent and meaningful sequence.

This is especially important in applications like:

  • Multi-document summarization
  • Question answering
  • Text generation systems

2. Objective of the Paper

The main goal of the paper is:

  • To develop a probabilistic model
  • To learn sentence ordering patterns from real text
  • To generate a coherent sentence sequence automatically

3. Problem Statement

When sentences are taken from different documents or summarized outputs, they lose their original order and become incoherent and confusing.

Traditional methods like chronological ordering and majority ordering do not always produce good results.

4. Proposed Solution

The paper proposes an unsupervised probabilistic approach that:

  • Learns ordering constraints from a corpus
  • Uses statistical patterns instead of manual rules
  • Focuses on local coherence between sentences

5. Methodology

5.1 Probabilistic Model

P(T) = P(S1) . P(S2|S1) . P(S3|S2) ... P(Sn|S(n-1))
  • Each sentence depends only on the previous sentence
  • This is called a Bigram Model

5.2 Feature-Based Representation

Instead of full sentences, the model uses features:

  • Verbs: capture actions and events
  • Nouns: capture entities (people, objects, organizations)
  • Dependencies: capture grammatical structure (subject-verb-object)

5.3 Probability Estimation

P(feature_i | feature_(i-1))

Estimated using frequency counts from corpus, to learn which features commonly follow others.

5.4 Smoothing Technique

Uses Katz Back-off smoothing to prevent zero-probability issues.

5.5 Sentence Ordering Algorithm

Uses a Greedy Algorithm:

  • Select most probable starting sentence
  • Choose next sentence with highest probability
  • Continue until all sentences are ordered

Reason: exact search is NP-complete and very slow.

5.6 Graph Representation

  • Sentences -> Nodes
  • Probabilities -> Edges

The task becomes finding the best path (order) in a graph.

6. Evaluation Method

The model is evaluated using Kendall's Tau (tau), measuring similarity between generated order and original human order.

  • +1: Perfect match
  • 0: Random
  • -1: Completely wrong

7. Experiments

Experiment 1: News Text Ordering

  • Model trained on BLLIP corpus
  • Tested on unseen articles
  • Best performance with noun features and verb + dependency features

Experiment 2: Human Comparison

  • Humans asked to reorder sentences
  • Model performance approximately close to human performance

Experiment 3: Multi-document Summarization

  • Sentences taken from different documents
  • Model produced coherent summaries better than random ordering

8. Key Results

  • Sentence ordering can be learned automatically
  • Local coherence is sufficient for good results
  • Nouns + dependencies are most effective features
  • Model performs close to human-level

9. Limitations

  • Considers only previous sentence (local context)
  • Does not fully capture deep semantics
  • Greedy algorithm may not give optimal solution

10. Applications

  • Text summarization systems
  • Question answering systems
  • AI content generation
  • Chatbots and NLP pipelines

11. Conclusion

The paper introduces a data-driven probabilistic approach for sentence ordering that learns from real-world text, requires no manual rules, and produces coherent and meaningful text.

Statistical patterns and local sentence relationships are sufficient to generate high-quality text structure.

4) Viva Quick Answers and Research Gap

What Is Parsing?

Parsing is the process of analyzing sentence grammar structure: who is doing what to whom. In NLP, dependency parsing identifies relations like Subject, Verb, and Object.

What Is Parse-Based Sentence Reordering?

It is arranging shuffled sentences into a coherent order using syntactic and discourse signals from parsing, entity continuity, pronoun flow, and temporal cues.

What Is a Heuristic?

A heuristic is a practical rule-based scoring strategy that gives fast, explainable decisions without full model training.

What We Are Building

We are building a heuristic + NLP ranking system (rule-guided scoring with spaCy linguistic features), not a large end-to-end transformer trainer.

Current System vs Trained Transformer Model

Model Type Strengths Trade-offs
Our Current Heuristic + spaCy Fast, explainable, low compute, no training required, easy debugging Lower peak accuracy, manual tuning needed, weaker on deep discourse
BERT/Transformer Training High accuracy, stronger global context modeling, better semantic capture Needs large data, heavier compute, harder to explain in viva

Most Related Single Paper and Why

Topological Sort for Sentence Ordering (ACL 2020) is the most related single paper for our current project stage because it focuses on ordering quality and global consistency improvement without requiring a full heavy training pipeline for deployment.

Research Gap in Lapata (2003)

  • Mainly local transitions (weak global discourse)
  • Independence assumptions simplify real linguistic dependencies
  • Greedy decoding can miss better global orders
  • Limited temporal/coreference/discourse reasoning
  • Evaluation mostly automatic ranking similarity
  • Domain transfer uncertainty

Common Limitations Across Modern Related Papers

  • Domain/data dependence on benchmark style
  • Scalability challenges as sentence count grows (often O(n^2))
  • Error propagation from pairwise/local decisions
  • Global coherence still approximated
  • High compute for BERT/graph rerank pipelines
  • Sensitivity to external knowledge source quality
  • Evaluation gap (automatic metrics more than strong human studies)
  • Limited robustness evidence on multilingual/very noisy OOD settings
