Project Documentation

Setup, architecture, usage, and API details for the Parsing-Based Sentence Reordering project.

Overview

  • Compares baseline and parsing-based sentence reordering methods
  • Uses Reuters-derived shuffled text for demonstration
  • Provides both web UI and REST API interfaces

Tech Stack

  • Backend: Flask (Python)
  • NLP: spaCy + NLTK Reuters corpus helpers
  • Frontend: Jinja templates, vanilla JavaScript, custom CSS
  • Auth: Firebase Google Sign-In integration

Setup

Install dependencies and start the server:

pip install -r requirements.txt
python app.py

Optional: configure Firebase environment variables for Google auth.

How To Use

  • Open Reorder page
  • Paste at least 3 sentences
  • Choose Baseline, Parsing, or Compare
  • Review output scores and order differences

API Endpoints

  • POST /api/reorder: reorder input text
  • GET /api/sample: fetch random Reuters dataset sample sentences only
  • POST /api/auth/google: verify Firebase ID token
  • GET /api/auth/status: current auth session status
  • GET /api/history: list saved runs

Methods Summary

  • Step 1: Parse Sentence
  • Dependency Parsing (Implemented)
  • Constituency Parsing (Planned)
  • Step 2: Apply Reordering
  • Rule-Based (Implemented)
  • Statistical (Planned)
  • Neural (Planned)
  • Step 3: Generate Output Sentence (Implemented)
